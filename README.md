# Boho Boho (बोहो बोहो) — Premium Bistro Website Concept Demo

A proposed client demonstration website for **Boho Boho**, an artisanal continental bistro and specialty coffee destination nestled in Koregaon Park, Pune.

## 🌿 Concept & Design Aesthetic
- **Visual Style:** Warm bohemian bistro aesthetic featuring ivory, warm cream, rust terracotta (`#B8522E`), soft sage olive (`#5F7652`), and deep espresso typography.
- **Authenticity:** Verified cafe interior/patio photography, authentic transcribed menu cards (60+ items), accurate price brackets, and honest reservations request flow.
- **Responsiveness:** Full mobile, tablet, and desktop fidelity with sticky mobile action bars and accessible touch targets.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or newer)
- npm or pnpm

### Running Locally
```bash
# 1. Install dependencies (if not already installed)
npm install

# 2. Start the Vite development server
npm run dev

# 3. Open in browser (typically http://localhost:3000 or http://localhost:5173)
```

### Production Build & Preview
```bash
# Build production bundle
npm run build

# Preview production build locally
npm run preview
```
